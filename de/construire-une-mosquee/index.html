In Tunesien: Eine Genehmigung ist Pflicht

In Tunesien baut man eine Moschee oder einen Gebetsraum nicht einfach so: Man braucht eine Genehmigung. Der schriftliche Antrag wird bei der Delegation gestellt, mit der Bescheinigung über die Schenkung oder Zweckbestimmung des Grundstücks, einem Lageplan, einem Architektenplan und einem Kostenvoranschlag. Er geht dann über das Gouvernorat an das Ministerium für religiöse Angelegenheiten, das ihn genehmigt oder ablehnt (insgesamt etwa 45 Tage). Gesetz Nr. 88-34 vom 3. Mai 1988 über die Moscheen.

Auch eine öffentliche Spendensammlung muss genehmigt sein: Bevor Sie für eine Baustelle in Ihrer Nähe spenden, lassen Sie sich die Genehmigung zeigen.

Andere Wege, einer Moschee zu helfen

Nicht jeder kann eine Moschee bauen, aber jeder kann ihr helfen: sich an ihrer Instandhaltung beteiligen, Teppiche, Wasser oder Bücher schenken, etwas Zeit für die Reinigung oder den Unterricht geben oder auf unserer Karte eine fehlende Moschee melden.
